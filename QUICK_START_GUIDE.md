# 🌱 GreenWise - Quick Start Guide
**Get Started in 5 Minutes!**

---

## 📥 Installation (Android 7.0+)
1. Download **app-arm64-v8a-release.apk** (18.5 MB)
2. Tap to install
3. Follow welcome screens
4. You're ready!

---

## 🗺️ Four Main Sections

### 💡 Daily Tips
- **One eco-tip every day**
- Read → Do → Mark as Done
- Pull down to see different tips
- Tap "Why it matters" to learn more

### 📊 Progress  
- **Weekly ring** - Complete all 7 days!
- **Streak counter** - Keep it going!
- **30-day heatmap** - See your consistency
- Track your eco-journey

### ♻️ Recycle & Trade-In
- **Local Philippines programs**
- **National collection points**
- **International resources**
- Tap "Open" to visit websites

### ⚙️ Settings
- **Dark mode** - Save battery, easy on eyes
- **Reduce motion** - Faster, accessible
- **Notifications** - Never miss a day

## ❓ Common Questions

**Q: Is it free?**  
A: Yes! No ads, no subscriptions.

**Q: Need internet?**  
A: No! Only for Recycling Directory links.

**Q: What if I miss a day?**  
A: No problem! Just continue tomorrow.

**Q: Can I see more tips?**  
A: Yes! Pull down to refresh on Daily Tips page.

**Q: How do I back up my progress?**  
A: Progress is device-only. Don't uninstall if you want to keep it!
